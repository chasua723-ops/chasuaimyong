# 맥북에서 이어서 작업하기 — 처음부터 끝까지

이 문서는 데스크탑 없이, 맥북과 (아무 기기에서 켠) Claude만으로 작업을 이어가기 위한 가이드예요.

## 1. 코드 받아오기

맥북에서 **터미널(Terminal) 앱**을 열고 (Cmd+Space → "Terminal" 검색) 아래를 입력하세요.

**처음이라면 (클론):**
```bash
mkdir -p ~/Documents/projects && cd ~/Documents/projects && git clone https://github.com/chasua723-ops/chasuaimyong.git imyong-app
```

**이미 클론했었다면 (최신 코드 받기):**
```bash
cd ~/Documents/projects/imyong-app && git pull
```

## 2. 비밀 설정 파일 만들기 (.env.local)

이 파일은 실제 비밀 키가 들어가는 파일이라 **이 문서(git에 커밋되는 파일)에는 절대 값을 적어두지 않아요.** 아래 6개 값이 필요해요:

```
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_URL=
SUPABASE_SERVICE_ROLE_KEY=
ANTHROPIC_API_KEY=
APP_PIN=
```

값을 구하는 방법:
- **Supabase 4개 값**: `supabase.com` 로그인 → 프로젝트 → Settings → API 에서 확인 (URL, anon key, service_role key)
- **ANTHROPIC_API_KEY**: `console.anthropic.com` → API Keys 에서 확인 (기존 키를 못 찾으면 새로 발급)
- **APP_PIN**: 원하는 4자리 숫자로 직접 정하거나, 데스크탑의 `.env.local` 파일을 열어서 그대로 복사 (Claude 채팅으로 값을 요청하지 말고, 파일을 직접 열어보거나 안전한 방법으로 옮기세요)

값을 다 구했으면 맥북 터미널에서:
```bash
cd ~/Documents/projects/imyong-app && nano .env.local
```
편집기가 열리면 위 6줄 형식으로 `키=값`을 채워서 붙여넣고, Ctrl+O → Enter → Ctrl+X로 저장.

확인: `cat .env.local` 쳤을 때 6줄 나오면 성공.

이 파일은 git에 안 올라가는 파일이라(비밀값이라서), 새 컴퓨터/새로 클론할 때마다 이 단계를 반복해야 해요.

## 3. Node.js 설치 (없다면)

```bash
node -v
```
"command not found"가 뜨면: 브라우저로 `nodejs.org` 접속 → 초록색 "LTS" 버튼 클릭 → 다운로드된 `.pkg` 파일 실행 → 계속/계속/동의/설치 순서로 진행.

## 4. 패키지 설치

```bash
cd ~/Documents/projects/imyong-app && npm install
```

**`ERR_SSL_CIPHER_OPERATION_FAILED` 에러가 뜨면:**
```bash
rm -rf node_modules && npm config set maxsockets 3 && npm install
```
그래도 안 되면 와이파이를 바꿔보세요 (핸드폰 테더링 등) — 특정 공유기/네트워크에서 잘 나는 에러예요.

## 5. Supabase DB 마이그레이션 (이미 완료됨 — 참고용)

`supabase.com` 로그인 → 프로젝트 → SQL Editor에서, `supabase/migrations/` 폴더 안의 `.sql` 파일들을 **번호 순서대로** 실행. (0001은 이미 처음에 했고, 0002도 오늘 이미 실행 완료했음 — 새 마이그레이션 파일이 생기면 그때 실행)

## 6. 로컬에서 확인

```bash
npm run dev
```
브라우저에서 `localhost:3000` 접속해서 PIN(3793) 입력하고 잘 뜨는지 확인.

## 7. Claude로 작업 이어가기

**어떤 Claude(웹, 앱, 터미널)든** `~/Documents/projects/imyong-app` 폴더를 열어서 새로 시작하고, 이렇게 말하면 돼요:

> "이 프로젝트 이어서 작업할게. `docs/superpowers/plans/`랑 `docs/superpowers/specs/` 폴더 최근 파일들 읽어보고, 지금까지 뭐가 됐고 뭐가 남았는지 파악해줘. 다음은 '오늘의 학습 더 풀기' 기능 브레인스토밍 시작하면 돼."

이 대화 세션이 없어도, git에 커밋된 설계서/계획서만으로 새 세션이 전체 맥락을 알 수 있게 만들어뒀어요.

**단, 주의할 점**: 저(Claude)의 "기억"(메모리) 기능은 지금 이 데스크탑 컴퓨터에만 저장되어 있어서, 맥북의 새 세션은 저와 나눈 대화 취향 같은 걸 자동으로는 몰라요. 하지만 프로젝트 관련 중요한 내용(설계, 계획, 진행상황)은 전부 git 파일로 남아있어서 기술적인 이어가기에는 문제없어요.

## 8. 작업 다 하고 나면

```bash
git add -A && git commit -m "작업 내용"
git push origin master
```

이렇게 해두면 데스크탑으로 나중에 돌아와도 `git pull`만 하면 다시 동기화돼요.
