# 임용고시 중국어 대비 15분 학습 앱 — 설계 문서

## 배경 및 목적

중등 임용고시 중국어 전공을 준비하는 1인 사용자를 위한 개인 학습 앱. 매일 15분씩,
본인이 가진 전공교재를 회독(반복 읽기)하면서 AI가 생성하는 문제/암기카드로 이해도를
점검한다. 실제 시험은 답안을 중국어로 작성해야 하므로, 서술형 문제는 한국어 내용 정리
→ 중국어 답안 작성의 2단계로 연습한다.

## 범위 (v1)

**포함:**
- 전공중국어 교재 3권 (문법, 문학개론, 어학개론) — PDF, OCR 텍스트 추출 가능
  - 회독 대상. 시험일 + 목표 회독 횟수 기반으로 일일 분량 자동 계산
- 기출문제 자료 6종 (기출문제2, 이론기출문제1, 독해편 기출문제2, 이론편 기출문제1,
  독해기출 특강, 교과교육학 기출문제집) — 답안/해설 포함 PDF
  - 사용자가 직접 푸는 트랙이 아니라, AI가 문제를 생성할 때 실제 출제 스타일·난이도·
    패턴을 참고하는 레퍼런스 자료로 활용
- 반응형 웹앱 (모바일 브라우저 + 데스크톱), 무료 클라우드 배포
- 공개 URL 접근이므로 PIN 1개로 접근 보호

**제외 (phase 2 이후로 연기):**
- 교육학 상/하 교재, 습관용어(어휘집) — 별도 회독 트랙 필요, 스코프 확장 시 추가

## 기술 아키텍처

- **Next.js** (App Router) — 프론트+백엔드 통합, Vercel 무료 배포
- **Supabase** — Postgres DB + 파일 저장소(PDF 원본) + 간단 PIN 인증
- **Anthropic Claude API** — 문제/카드 생성, 서술형 채점, 오답 설명, 어휘 큐레이션
- **GitHub 저장소** → Vercel 연동 자동 배포

### 데이터 모델 (핵심 테이블)

- `books` — 문법/문학개론/어학개론. 총 페이지 수, 시험일, 목표 회독 횟수, 현재 회독 차수
- `book_pages` — book_id, page_num, 추출된 텍스트 (PDF 업로드 시 1회 추출)
- `reference_materials` — 기출문제 6종의 추출 텍스트. 문제 생성 시 스타일 참고용 컨텍스트로만 사용 (사용자 학습 진도 추적 대상 아님)
- `study_progress` — book_id, 현재 페이지 위치, 완료한 날짜, 회독 차수별 이력
- `daily_sessions` — 날짜, 오늘 배정된 각 책의 페이지 범위, 오늘의 서술형 대상 책, 완료 여부
- `questions` — AI 생성 문제. book_id, 출처 페이지, 유형(문법/어휘/독해/문학·어학이론/서술형), 정답 또는 모범답안, reference_materials 참고 여부
- `attempts` — 사용자 응답, 정오답, AI 설명(+출처 페이지), 서술형의 경우 한국어 답/중국어 답 별도 저장 + 각각 평가(내용 정확도 / 중국어 표현) 결과
- `category_stats` — 유형별 누적 정답률 (적응형 배분에 사용)
- `vocab_of_the_day` — AI가 큐레이션한 최신 트렌드 어휘, 교재 외 콘텐츠로 명확히 라벨링

모든 문제 생성·채점·설명은 해당 범위의 `book_pages` 텍스트를 근거(RAG)로 하며, 교재
범위 밖 내용이면 명시적으로 표시한다. 단, "오늘의 어휘"는 예외로 AI가 자체 지식으로
큐레이션하며 출처를 "AI 큐레이션"으로 구분 표기한다.

## 일일 학습 흐름 (15분 세션)

1. 접속 시 오늘 날짜 기준 세 교재 각각의 회독 범위(페이지) 표시 (자동 계산, 필요시 수동 조정 가능)
2. 각 교재별 AI 생성 퀴즈/암기카드 몇 문항 제공 (해당 범위 텍스트 근거, 기출문제 스타일 참고)
   - 유형별 누적 정답률에 따라 취약 유형(특히 독해) 비중을 자동으로 높임
3. 오답 시 → 교재 근거 설명 + 출처 페이지 번호 표시
4. 세 교재 중 오늘 배정된 한 교재에 서술형 1문항 추가
   - 1단계: 한국어로 내용 정리 답안 작성
   - 2단계: 중국어로 실제 시험처럼 답안 작성
   - 두 답안 별도 저장, 각각 평가(내용 정확도 / 중국어 표현) + 교재 근거 피드백
5. "오늘의 어휘" 코너 — AI가 큐레이션한 최신 임용 출제 경향 어휘 (교재 외, 별도 라벨)
6. 완료 시 해당 범위를 읽음으로 체크 → 회독 진행률 갱신, category_stats 갱신

## 에러 처리 및 예외 상황

- PDF 텍스트 추출 실패/품질 저하 (OCR 오류) — 해당 페이지 범위는 "텍스트 품질 낮음"으로
  표시하고 사용자가 수동으로 건너뛰거나 재시도 가능
- AI 생성 실패/API 오류 — 재시도 로직, 반복 실패 시 해당 세션은 회독 체크만 가능하도록 폴백
- 회독 목표일이 지났거나 남은 일수가 목표 분량 대비 부족한 경우 — 일일 분량 자동 재계산 시 경고 표시
- 서술형 답안 미제출(1단계만 하고 중단) — 부분 저장 허용, 미완료 상태로 표시

## 테스트 계획

- PDF 텍스트 추출 파이프라인: 실제 3권 교재로 추출 정확도/페이지 매핑 검증
- 일일 분량 자동 계산 로직: 다양한 (남은 일수, 목표 회독 횟수, 총 페이지) 조합 단위 테스트
- AI 문제 생성: 샘플 페이지 범위로 생성 결과가 실제로 해당 범위 내용에 근거하는지 검토
- 서술형 채점: 샘플 답안(정답/오답/부분정답)에 대한 평가 일관성 확인
- 적응형 배분: 특정 유형 정답률을 인위적으로 낮춰서 해당 유형 비중이 실제로 높아지는지 확인
- E2E: 하루 세션 전체 흐름(접속 → 문제 풀이 → 서술형 → 완료 체크)을 모바일/데스크톱 브라우저에서 수동 검증
